# 마중물 — 물 마시기 기록 & 알림

마중물은 펌프에서 물이 나오게 하려고 **먼저 붓는 한 바가지의 물**을 말합니다.
오늘의 첫 잔이 하루의 물길을 틔우기를 바라며 붙인 이름입니다.

마신 물의 **양과 횟수**를 남기고, 정해진 시간이 되면 **물 마시라고 불러 주는** 웹앱입니다.
빌드 도구나 서버 없이 순수 HTML/CSS/JS 로 만들었고, 기록은 브라우저(localStorage)에만 저장됩니다.

## 실행 방법

```bash
# 저장소 루트에서 (짐메이트는 http://localhost:8080/gymmate/ 로 열립니다)
npx http-server -p 8080 .
# → http://localhost:8080/majungmul/
```

`index.html` 을 그냥 열어도 화면은 뜨지만, **알림과 홈 화면 설치는 https 주소에서만** 동작합니다.
아래 GitHub Pages 배포를 쓰세요.

## 휴대폰에서 앱처럼 쓰기 (알림을 받으려면 필수)

1. 저장소 **Settings → Pages → Source** 를 `GitHub Actions` 로 선택
2. 이 브랜치를 push 하면 `.github/workflows/pages.yml` 이 자동 배포
   (주소는 보통 `https://<계정>.github.io/test/majungmul/`)
3. **안드로이드 Chrome** — 주소창 오른쪽 `⋮` → *앱 설치* 또는 *홈 화면에 추가*
   **아이폰 Safari** — 공유 버튼 → *홈 화면에 추가*
4. 앱을 열고 **알림 탭 → 물 마실 시간 알림** 을 켜고 권한을 허용

> 아이폰은 **홈 화면에 설치한 경우에만** 웹앱 알림을 받을 수 있습니다(iOS 16.4 이상).
> 사파리 탭으로 열어 두면 알림이 오지 않습니다.

## 기능

### 오늘
- 물잔이 마신 만큼 차오르고, 목표를 채우면 초록으로 바뀝니다
- **빠른 추가 버튼**(기본 100 / 200 / 350 / 500 mL) 한 번으로 기록 — 버튼 양은 설정에서 바꿉니다
- 직접 입력, 방금 기록 **되돌리기**, 기록 하나씩 삭제
- 오늘 마신 양·횟수·잔 수와 다음 알림 시각을 한 화면에

### 기록
- 최근 2주 막대그래프 (목표선 표시, 달성한 날은 초록)
- 날짜를 누르면 그날 마신 시각과 양
- 연속 달성일, 7일 평균·달성률, 30일 평균

### 알림
두 가지 방식 중에 고릅니다.

| 방식 | 동작 |
| --- | --- |
| **일정 간격** | 30분 / 1시간 / 1.5시간 / 2시간 / 3시간 / 직접 입력 |
| **정한 시각** | 09:00, 13:00 … 처럼 시각을 직접 넣어 둠 |

- **부르는 시간대**(기본 08:00~22:00)와 **요일**을 정해 자는 동안에는 부르지 않습니다
- *마시면 간격을 다시 셈* — 방금 마셨으면 그 시각부터 다시 셉니다
- *목표를 채우면 그만 부르기* — 다 마신 날은 더 부르지 않습니다
- 알림에 뜨는 **`한 잔 마셨어`** 버튼을 누르면 앱을 열지 않아도 한 잔이 기록됩니다
- **`조금 뒤에`** 를 누르면 정한 시간(기본 20분)만큼 미룹니다
- 알림음(물방울 소리)·진동, `지금 한 번 보내 보기` 로 미리 확인

### 설정
- 하루 목표 (몸무게 × 30 mL 정도가 흔한 기준)
- 빠른 추가 버튼 편집, 한 잔 기준
- **하루가 바뀌는 시각** — 기본 새벽 4시. 새벽에 마신 물이 전날 기록으로 들어갑니다
- **실행 인트로** — 앱을 완전히 껐다 켜면 물방울이 떨어져 파문이 이는 장면이 잠깐 보입니다.
  `기기 설정` / `항상 보기` / `사용 안 함` 중에 고르고, `인트로 다시 보기`로 바로 확인할 수 있습니다.
  기기의 **동작 줄이기**가 켜져 있으면 움직임 없이 그림만 보여 주며, 지금 어느 쪽인지 설정 화면에 그대로 적어 둡니다
- 백업 내보내기 / 가져오기 (.json), 기록 전체 지우기

## 알림이 얼마나 정확한가 (솔직한 한계)

브라우저에는 "이 시각에 깨워 줘" 하고 예약해 두는 방법이 없습니다.
그래서 알림은 두 갈래로 굴립니다.

| 상황 | 동작 |
| --- | --- |
| 앱이 켜져 있거나 백그라운드에 남아 있을 때 | 앱 안의 시계가 15초마다 확인해 **정확한 시각에** 알립니다 |
| 앱 화면을 보고 있을 때 | 시스템 알림 대신 화면 안에서 조용히 알려 줍니다 |
| 앱을 완전히 닫았을 때 | 서비스워커의 주기 동기화에 기댑니다. **안드로이드 크롬에 설치한 경우에만** 동작하고 시각도 몇 분 어긋날 수 있습니다 |
| 그마저 안 됐을 때 | 앱을 여는 순간 밀린 알림을 따라잡아 알려 줍니다 |

**앱을 완전히 종료해도 정확히 받고 싶다면 캘린더를 쓰세요.**
알림 탭 맨 아래 `휴대폰 캘린더에 알림 등록` 을 누르면 지금 설정한 시각을
매일 울리는 일정 파일(.ics)로 내려받습니다. 받은 파일을 열면 캘린더에 들어가고,
그 뒤로는 앱을 꺼 두어도 **휴대폰이 직접** 알려 줍니다(아이폰·안드로이드 모두).
지우려면 캘린더에서 "물 마실 시간" 을 찾아 삭제하면 됩니다.

알림 탭에는 **진단**이 함께 있습니다. 권한·설치 여부·백그라운드 가능 여부를
이 기기 기준으로 하나씩 보여 주므로, "알림이 안 온다" 의 원인을 화면에서 바로 알 수 있습니다.

즉 **홈 화면에 설치해 두고 앱을 완전히 종료하지 않는 것**이 가장 잘 동작합니다.
서버로 푸시를 보내지 않으므로(기록을 밖으로 내보내지 않으려고 그렇게 만들었습니다)
이보다 더 정확하게 하려면 알림 서버가 필요합니다.

## 파일

```
majungmul/
├── index.html          화면 뼈대 · 인트로 · 서비스워커 등록
├── manifest.json       홈 화면 설치 정보
├── sw.js               오프라인 캐시 · 앱이 꺼져 있을 때의 알림
├── css/styles.css      물빛 다크 테마
├── js/store.js         기록·설정 저장소 (localStorage)
├── js/remind.js        알림 시각 계산과 발송
├── js/app.js           화면 그리기와 조작
├── icons/              앱 아이콘 (tools/build-icons.js 로 생성)
└── tools/build-icons.js
```

알림 계획은 페이지와 서비스워커가 함께 봐야 해서 localStorage 가 아니라
Cache Storage(`majungmul-state`)에 따로 넣어 둡니다. 서비스워커는 localStorage 를 볼 수 없습니다.

```bash
node majungmul/tools/build-icons.js   # 아이콘 다시 만들기 (Playwright 필요)
```
