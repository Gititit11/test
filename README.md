# GymMate — 헬스 루틴 & 세트 체크 앱

머신·프리웨이트를 **검색**해서 나만의 헬스 루틴을 만들고, 운동 중에는 **한 세트를 끝낼 때마다 체크**하며 진행하는 웹앱입니다.
빌드 도구나 서버가 필요 없는 순수 HTML/CSS/JS로 만들어졌고, 모든 데이터는 브라우저(localStorage)에 저장됩니다.

## 실행 방법

```bash
# 1) 가장 간단한 방법 — index.html 을 브라우저로 열기
# 2) 로컬 서버로 실행 (오프라인 캐시·PWA 설치까지 사용하려면 권장)
npx http-server -p 8080 .
# → http://localhost:8080
```

휴대폰에서 주소를 열고 “홈 화면에 추가”를 하면 앱처럼 전체 화면으로 실행됩니다.
서비스워커가 자산을 캐시하므로 헬스장에서 네트워크가 끊겨도 동작합니다.

## 주요 기능

### 1. 운동 검색 (내장 115종)
- 가슴 / 등 / 어깨 / 팔 / 하체 / 코어 / 유산소 × 머신 / 케이블 / 바벨 / 덤벨 / 스미스 / 맨몸 / 기타
- 한글 이름, 영문 이름, 자극 부위, 장비명으로 검색 (`랫풀다운`, `machine`, `광배근` 모두 가능)
- **초성 검색** 지원 — `ㅂㅊㅍ` → 벤치프레스, `ㅅㅋㅌ` → 스쿼트
- 부위·장비 필터 칩으로 좁혀 보기
- 원하는 운동이 없으면 **직접 추가**해서 내 운동 목록에 등록

### 2. 루틴 만들기
- 루틴 이름·메모 지정, 운동 순서 위/아래 이동, 복제·삭제
- 운동별로 **세트 수**와 **세트당 횟수·무게**를 개별 지정 (1세트 60kg×12, 2세트 70kg×10 처럼 세트마다 다르게 가능)
- `1세트 값으로 전체 채우기` 버튼으로 한 번에 정리
- 운동별 **휴식 시간**과 메모(핀 번호, 등받이 칸 등) 저장
- 플랭크·유산소 등은 횟수 대신 **시간(초)** 기준으로 기록

### 3. 운동 중 세트 체크
- 세트마다 큼직한 체크 버튼 — 누르면 완료 처리되고 **휴식 타이머가 자동 시작**
- 휴식 종료 시 알림음 + 진동, `+15초 / -15초 / 건너뛰기`
- 진행률 바, 경과 시간, 실시간 총 볼륨(무게×횟수) 표시
- 실제로 든 무게·횟수가 계획과 다르면 그 자리에서 수정 후 체크
- 운동 중 세트 추가/삭제 가능
- 진행 상태가 즉시 저장되어 **앱을 닫았다 열어도 이어서** 진행

### 4. 기록
- 완료한 운동은 날짜·소요 시간·완료 세트 수·총 볼륨과 함께 저장 (체크하지 않은 세트는 제외)
- 최근 7일 운동 횟수와 볼륨 요약
- 기록 상세에서 세트별 무게·횟수 확인

### 5. 설정
- 기본 휴식 시간, 무게 단위(kg/lb), 알림음 on/off
- 내가 추가한 운동 관리
- **JSON 내보내기 / 가져오기** 백업, 전체 초기화

## 파일 구조

```
index.html        앱 셸
manifest.json     PWA 매니페스트 (홈 화면 설치)
sw.js             오프라인 캐시용 서비스워커
css/styles.css    다크 테마 스타일 (모바일 우선)
js/exercises.js   내장 운동 DB 115종 + 검색(초성 포함)
js/store.js       localStorage 저장소 · 루틴/세션/기록 CRUD
js/app.js         라우팅 · 화면 렌더링 · 휴식 타이머
```

## 데이터 보관 위치

모든 데이터는 `localStorage`의 `gymmate.v1` 키에 저장되며 서버로 전송되지 않습니다.
브라우저 데이터를 지우면 함께 삭제되므로, 기기를 바꾸기 전에 **설정 → JSON 내보내기**로 백업하세요.
