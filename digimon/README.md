# 디지타마 (디지몬 육성)

실시간으로 디지몬을 돌보는 다마고치형 육성 웹앱입니다. 바코드를 찍으면 야생 디지몬이 나와서
배틀할 수 있습니다. 바이탈 브레스 도트를 쓰고, 이름은 한국 더빙판(나무위키 표기)을 따릅니다.

돌보기 → 훈련 → 바코드 배틀 → 진화 → 도감 수집

**안드로이드 앱 받기**: https://github.com/Gititit11/test/releases/download/digitama-latest/digitama.apk
(폰에서 누르면 받아짐 → 설치. 처음 한 번은 '출처를 알 수 없는 앱' 허용이 필요. 새 버전은 같은 주소에서 받아 덮어 설치하면 키우던 디지몬이 그대로 남음)

## 쓰는 법

1. **디지타마 고르기**: 아구몬 · 파피몬 · 브이몬 중 하나를 고르면 바로 부화합니다
2. **돌보기**: 먹이, 간식, 훈련, 청소, 불 끄기를 합니다. 배고픔이나 힘이 0칸이 되면 화면에 **!** 가 뜹니다
3. **바코드 배틀**: 성장기부터 할 수 있습니다. 카메라로 찍거나 바코드 아래 숫자를 넣습니다
4. **진화**: 단계 시간이 끝나면 그동안 쌓인 값으로 판정합니다. 잘못된 진화가 오기 하루 전부터 디지몬 색이 어두워집니다
5. **보관함**: 여러 마리를 데리고 있을 수 있습니다 (최대 6마리). 새 알을 받으면 키우던 디지몬은 보관함으로 갑니다.
   **보관함의 디지몬은 시간이 멈춰서** 배고파지지도, 나이를 먹지도, 진화하지도 않습니다. 데려오면 멈춘 데서 이어집니다
6. **도감**: 키우거나 이긴 디지몬은 그림, 만나기만 한 디지몬은 실루엣과 이름으로 보입니다.
   칸을 누르면 진화 전후와 조건을 볼 수 있습니다

## 기획안

### 돌보기

| 항목 | 내용 |
| --- | --- |
| 단계 시간 | 유년기1 1시간, 유년기2 24시간, 성장기 72시간, 성숙기 96시간, 완전체 120시간, 궁극체는 수명까지 |
| 수명 | 부화부터 20일. 성숙기 → 완전체 진화에 실패하면 하루 줄어듦 |
| 케어 실수 | 배고픔·힘 0칸 호출을 15분 넘게 두면 1 (호출 한 번에 1회) |
| 위생 실수 | 배변을 3시간 넘게 두면 1 |
| 과식 | 배고픔이 가득한데 먹이나 간식을 주면 1 |
| 수면 방해 | 잠든 뒤 30분 넘게 불을 안 끄면 1 (하룻밤에 한 번), 자는 걸 깨우면 1 |
| 훈련 | 미니게임 한 판에 1. 세 번 중 두 번 맞히면 힘이 오름 |
| 취침 시간 | 유년기2 20–8시, 성장기·성숙기 21–7시, 완전체 이상 22–7시 (기기 시각) |
| 수치 초기화 | 진화하거나 진화에 실패하면 쌓인 값을 비우고 다시 셈 |

### 진화 조건

번호는 진화 트리에 쓰입니다. 표에 적힌 순서대로 보고, 처음 맞는 조건으로 진화합니다.

| 번호 | 단계 | 조건 |
| --- | --- | --- |
| ① 정상 | 성장기 | 케어 실수 0–3, 훈련 16–47 |
| ② 중간 | 성장기 | 다른 조건에 맞지 않을 때 |
| ③ 실패 | 성장기 | 케어 실수 6 이상 |
| ④ 실패 | 성장기 | 위생 실수 4 이상 또는 과식 6 이상 |
| ⑫ 다크 | 성장기 | 수면 방해 4 이상 |
| ⑤ 정상 | 성숙기 | 케어 실수 2 이하, 배틀 15 이상, 승률 60% 이상 |
| ⑥ 폭주 | 성숙기 | 훈련 48 이상, 배고픈 채 배틀 5 이상 |
| ⑦ 숨은 | 성숙기 | ⑤ + 승률 80% 이상 |
| ⑧ 숨은 | 성숙기 | 케어 실수 0, 배틀 15 이상, 승률 40% 이상 |
| ⑬ 정화 | 성숙기 | ⑤ 와 같음 |
| ⑭ ⑱ | 성숙기 | 앞 조건에 못 미칠 때 |
| ⑳ 중간 | 성숙기 | 케어 실수 3–5, 배틀 15 이상, 승률 60% 이상 |
| ⑨ 정상 | 완전체 | 케어 실수 1 이하, 승률 70% 이상, 보스 격파 1 이상 |
| ⑪ 폭주 | 완전체 | 5연패, 케어 실수 3 이상 |
| ⑮ 숨은 | 완전체 | ⑨ + 수면 방해 0 |
| ⑩ 조그레스 | 궁극체 | 워그레이몬은 메탈가루몬을, 메탈가루몬은 워그레이몬을 키워 본 적 있고 보스 3번 격파 → 오메가몬 |
| ⑲ 모드 체인지 | 궁극체 | 황제드라몬 드래곤 모드로 보스 3번 격파 → 파이터 모드 |
| ⑯ 아머진화 | 성장기 | 브이몬 + 용기·우정·사랑의 디지멘탈 → 화염드라몬·번개드라몬·사수몬 (48시간, 하루 1회) |
| ⑰ 아머진화 | 성장기 | 브이몬 + 기적의 디지멘탈 → 매그너몬 (완전체 아머체) |

맞는 조건이 없으면: 성숙기는 그대로 남고 수명이 하루 줄어듭니다. 완전체는 그대로 남습니다.

### 진화 트리

**아구몬 라인**: 깜몬 → 코로몬 → 아구몬

- 아구몬: ④ 씨라몬 · ③ 아르고몬 · ① 그레이몬 · ② 우가몬
- 그레이몬: ⑥ 스컬그레이몬 · ⑤ 메탈그레이몬 · ⑳ 메탈티라노몬
- 우가몬: ⑦ 콩알몬 · ⑤ 안드로몬
- 아르고몬: ⑧ 네오데블몬 → ⑨ 던데블몬
- 씨라몬: ⑤ 스콜피오몬
- 메탈그레이몬: ⑨ 워그레이몬 → ⑩ 오메가몬
- 메탈티라노몬: ⑪ 블리츠그레이몬

**파피몬 라인**: 푸니몬 → 뿔몬 → 파피몬

- 파피몬: ③④ 아르고몬 · ⑫ 스파이더몬 · ① 가루몬 · ② 고릴라몬
- 가루몬: ⑥ 패럿몬 · ⑤ 워가루몬
- 스파이더몬: ⑬ 워가루몬 · ⑭ 워시드라몬 → ⑨ 니드호그몬
- 고릴라몬: ⑦ 빅콩알몬 · ⑤ 밸브몬
- 아르고몬: ⑧ 오로치몬
- 워가루몬: ⑮ 크레스가루몬 · ⑨ 메탈가루몬 → ⑩ 오메가몬

**브이몬 라인**: 치코몬 → 꼬마몬 → 브이몬

- 브이몬: ③④ 디지타몬 · ① 엑스브이몬 · ② 브이드라몬
- 브이몬 아머진화: 화염드라몬 · 번개드라몬 · 사수몬 · 매그너몬
- 엑스브이몬: ⑤ 파일드라몬 → ⑨ 황제드라몬 드래곤 모드 → ⑲ 황제드라몬 파이터 모드 · ⑱ 다이노몬
- 브이드라몬: ⑦ 골드브이드라몬 · ⑤ 에어로브이드라몬 → ⑨ 알포스브이드라몬

막다른 진화(스컬그레이몬, 안드로몬, 콩알몬, 스콜피오몬, 패럿몬, 밸브몬, 빅콩알몬, 오로치몬, 다이노몬,
골드브이드라몬, 디지타몬)는 더 진화하지 않는 대신 전투력이 1.3배입니다.

### 바코드 배틀

- **하루 5번** 스캔할 수 있습니다 (모든 디지몬이 함께 씀). 어떤 바코드를 찍어도 **매번 새로 뽑습니다**
- 나오는 단계: 내 단계와 같은 단계 70%, 한 단계 위 30%. 궁극체는 궁극체만 만납니다. 아머체는 그 아머체의 단계로 칩니다
- 나온 단계별 등급 확률

  | 단계 | 일반 | 희귀 | 보스 | 전설 |
  | --- | --- | --- | --- | --- |
  | 성장기 · 성숙기 | 75% | 25% | — | — |
  | 완전체 | 70% | 24% | 6% | — |
  | 궁극체 | 73.7% | 24% | 2% | 0.3% |

- 일반·희귀의 속성: 백신 30%, 데이터 30%, 바이러스 30%, 프리 10% (그 단계에 없는 속성이면 다른 속성)
- 전투력: 성장기 10, 성숙기 20, 완전체 34, 궁극체 52. 희귀 1.2배, 보스 1.45배, 전설 1.8배
- 상성: 백신 → 바이러스 → 데이터 → 백신 (유리하면 1.3배). 프리는 상성 없음
- 공격(명중 90%), 필살기(55%, 2배), 방어(받는 피해 40%) 중 골라 턴제로 싸웁니다. 배틀 중에 닫으면 패배
- 블리츠그레이몬은 35% 확률로 명령을 무시합니다. 아머체는 보스·전설에게 1.5배 강합니다
- **보상**: 완전체 보스를 이기면 아직 없는 디지멘탈(용기·우정·사랑) 하나, 궁극체 보스나 전설을 이기면
  기적의 디지멘탈. 이미 있으면 디지 칩 (배고픔과 힘을 가득 채움, 과식으로 치지 않음)

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `js/data.js` | 기획안의 표: 종, 진화 트리(`LINES[라인].evo`), 조건 설명, 야생 풀, 보스, 수치 (`RULES`) |
| `js/engine.js` | 게임 규칙: 시간 흐름, 보관함, 케어 판정, 진화 판정, 야생 뽑기, 배틀. DOM 을 쓰지 않음 |
| `js/sprite.js` | 디지몬 그리기 (시트 애니메이션, 없으면 임시 도트) |
| `js/sheets.js`, `sprites/` | 도트 시트와 목록 (`tools/import-sheets.py` 가 만듦) |
| `js/app.js` | 화면 흐름 |
| `js/install.js` | "앱 설치" 버튼 (다른 앱과 같은 파일) |
| `sw.js` | 오프라인 캐시 (웹으로 열 때만) |
| `android/` | 웹앱을 APK 안에 넣어 WebView 로 띄우는 안드로이드 앱. `.github/workflows/digimon-apk.yml` 이 만들어 릴리스 `digitama-latest` 에 올림 |
| `test/engine.test.js` | 규칙 시험 (`TZ=UTC node --test digimon/test/*.test.js`) |
| `tools/build-icons.py` | 아이콘 다시 만들기 (`python3 digimon/tools/build-icons.py`) |

수치를 조이거나 풀 때는 `js/data.js` 의 `RULES` 만 고치면 됩니다.
시험용으로 주소 뒤에 `?dev=1` 을 붙이면 정보 화면에 시간 건너뛰기 버튼이 생깁니다.

## 알아 둘 점

- **앱이 닫혀 있으면 알림이 오지 않습니다.** 웹앱은 서버 없이 백그라운드 알림을 보낼 수 없어서,
  호출 15분 규칙은 앱을 자주 열어 봐야 지킬 수 있습니다. 앱을 다시 열면 그사이 일을 한꺼번에 계산합니다.
- **카메라 바코드 인식**은 안드로이드 크롬처럼 `BarcodeDetector` 가 있는 브라우저에서만 됩니다.
  아이폰 사파리에서는 바코드 아래 숫자를 직접 넣어 주세요.
- **저장 형식이 바뀌었습니다** (`digimon:v2`). 스타터 6종 시절의 저장은 이어 쓰지 않고 새로 시작합니다.
- **그림**: 바이탈 브레스 도트가 `sprites/<id>.png` 에 들어 있습니다. 앱에 쓰는 155종은 모두 시트가 있고,
  나머지는 나중에 넣을 수 있게 남겨 둔 것입니다 (길몬 EX 등). 시트는 처음 그릴 때 하나씩 불러옵니다.
  ```bash
  # 256x256 PNG (4x3 칸) 한 장 → 손실 없이
  python3 digimon/tools/import-sheets.py png 원본.png --id agumon
  # 한 줄에 12칸씩 여러 디지몬이 있는 큰 그림 (검은 배경, JPEG 도 됨)
  python3 digimon/tools/import-sheets.py grid 사진.jpg --ids vorvomon,lavorvomon,...
  ```
  프레임 순서는 서기 2 · 걷기 2 · 달리기 2 · 훈련 2 · 기쁨 · 잠 · 공격 · 먹기 이고,
  회색 실루엣이나 빈 칸은 그 동작이 없는 것으로 칩니다.
  개인 비상업용으로 쓰는 팬 도트입니다. GitHub Pages 는 공개되므로 권리자 요청이 오면 내려야 합니다.
- 저장은 기기 안(localStorage)에만 합니다. 브라우저 데이터를 지우면 키우던 디지몬도 사라집니다.
