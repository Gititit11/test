# 디지타마 (디지몬 육성)

실시간으로 디지몬을 돌보는 다마고치형 육성 웹앱입니다. 실물 바코드를 스캔하면
야생 디지몬이 나와서 배틀할 수 있습니다. 같은 바코드에서는 늘 같은 디지몬이 나옵니다.

돌보기 → 훈련 → 바코드 배틀 → 진화 → 도감 수집

## 쓰는 법

1. **디지타마 고르기**: 6종 중 하나를 고르면 바로 부화합니다
2. **돌보기**: 먹이, 간식, 훈련, 청소, 불 끄기를 합니다. 배고픔이나 힘이 0칸이 되면 화면에 **!** 가 뜹니다
3. **바코드 배틀**: 성장기부터 할 수 있습니다. 카메라로 찍거나 바코드 아래 숫자를 넣습니다
4. **진화**: 단계 시간이 끝나면 그동안 쌓인 값으로 판정합니다. 잘못된 진화가 오기 하루 전부터 디지몬 색이 어두워집니다

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `js/data.js` | 기획안의 표: 종, 진화 라인, 야생 풀, 보스, 수치 (`RULES`) |
| `js/engine.js` | 게임 규칙: 시간 흐름, 케어 판정, 진화 판정, 바코드 → 디지몬, 배틀. DOM 을 쓰지 않음 |
| `js/sprite.js` | 디지몬 그리기 (시트 애니메이션, 없으면 임시 도트) |
| `js/sheets.js`, `sprites/` | 도트 시트와 목록 (`tools/import-sheets.py` 가 만듦) |
| `js/app.js` | 화면 흐름 |
| `js/install.js` | "앱 설치" 버튼 (다른 앱과 같은 파일) |
| `sw.js` | 오프라인 캐시 |
| `test/engine.test.js` | 규칙 시험 (`node --test digimon/test/*.test.js`) |
| `tools/build-icons.py` | 아이콘 다시 만들기 (`python3 digimon/tools/build-icons.py`) |

수치를 조이거나 풀 때는 `js/data.js` 의 `RULES` 만 고치면 됩니다.
시험용으로 주소 뒤에 `?dev=1` 을 붙이면 정보 화면에 시간 건너뛰기 버튼이 생깁니다.

## 기획안과 다른 점

- **임프몬 스타터 추가**: 즈루몬 → 야몬 → 임프몬 → 데빌드라몬 → 아스타몬 → **베르제브몬**.
  중간 루트는 바케몬입니다. 진화 조건은 다른 라인의 정상 조건과 같습니다.
- **보스 교체**: 베르제브몬이 임프몬의 궁극체가 되어서, 궁극체 보스 자리는 **아포칼리몬**(바이러스)으로 바꿨습니다.

## 기획안에 없어서 정한 것

| 항목 | 정한 내용 |
| --- | --- |
| 호출 | 배고픔 0칸, 힘 0칸일 때 호출. 깨어 있는 동안 15분이 지나면 케어 실수 1 (호출 한 번에 1회만 셈) |
| 힘 | 간식이나 훈련(3번 중 2번 성공)으로 오름. 배틀 전투력에 들어감 |
| 줄어드는 주기 | 배고픔은 성장기 기준 1시간에 1칸, 배변은 3시간에 1번. 자는 동안은 멈춤 |
| 취침 시간 | 유년기2 20–8시, 성장기·성숙기 21–7시, 완전체 이상 22–7시 (기기 시각). 깨우면 10분 뒤 다시 잠 |
| 수명 | 부화부터 20일. 성숙기 → 완전체 진화에 실패하면 하루 줄어듦 |
| 진화 실패 | 수치를 비우고 그 단계 시간만큼 다시 키운 뒤 재판정 |
| 중간 루트 | 티라노몬, 유키다루몬, 유니몬, 다크티라노몬, 바케몬은 더 진화하지 않음 |
| 스카몬 구제 | 성공하면 그 라인의 정상 성숙기(그레이몬 등)로 바로 진화 |
| 세대를 넘어 남는 것 | 도감, 디지멘탈, 디지 칩, 지난 디지몬 기록 |
| 디지멘탈 | 처음 보스를 이기면 받음. 보스는 완전체부터 나오므로 보통 다음 세대 브이몬이 씀 |
| 특수 아이템 | **디지 칩**: 배고픔과 힘을 가득 채움 (과식으로 치지 않음) |
| 플레이드라몬 | 배틀에서 성숙기로 쳐서 완전체 보스도 만남. 보스에게 1.5배 강함 |
| 궁극체의 야생 상대 | 궁극체 야생 풀이 없어서, 완전체 풀의 디지몬이 궁극체 세기로 나옴 |
| 배틀 | 공격(명중 90%), 필살기(55%, 2배), 방어(받는 피해 40%) 중 골라 턴제로 싸움. 상성 유리하면 1.3배 |
| 도망 | 배틀 중에 닫으면 패배로 기록 |
| 메기드라몬 | 35% 확률로 명령을 무시하고 아무 행동이나 함 |

## 알아 둘 점

- **앱이 닫혀 있으면 알림이 오지 않습니다.** 웹앱은 서버 없이 백그라운드 알림을 보낼 수 없어서,
  호출 15분 규칙은 앱을 자주 열어 봐야 지킬 수 있습니다. 앱을 다시 열면 그사이 일을 한꺼번에 계산합니다.
- **카메라 바코드 인식**은 안드로이드 크롬처럼 `BarcodeDetector` 가 있는 브라우저에서만 됩니다.
  아이폰 사파리에서는 바코드 아래 숫자를 직접 넣어 주세요. 결과는 같습니다.
- **그림**: 바이탈 브레스 도트 203종이 `sprites/<id>.png` 에 들어 있습니다 (카드 13장: 아구몬, 가브몬,
  에인션트 워리어즈, 허밋 인 더 정글, 뉴 메탈 엠파이어, 인피니트 타이드, 타이탄 오브 더스트,
  다이너스티 오브 디 이블, 매드 블랙 로어, 트루 섀도 하울, 임펄스 시티, 볼케닉 비트, 블리자드 팽).
  시트가 없는 종은 임시 도트로 그립니다. 시트는 처음 그릴 때 하나씩 불러옵니다.
  ```bash
  # 256x256 PNG (4x3 칸) 한 장 → 손실 없이
  python3 digimon/tools/import-sheets.py png 원본.png --id agumon
  # 한 줄에 12칸씩 여러 디지몬이 있는 큰 그림 (검은 배경, JPEG 도 됨)
  python3 digimon/tools/import-sheets.py grid 사진.jpg --ids vorvomon,lavorvomon,...
  ```
  프레임 순서는 서기 2 · 걷기 2 · 달리기 2 · 훈련 2 · 기쁨 · 잠 · 공격 · 먹기 이고,
  회색 실루엣이나 빈 칸은 그 동작이 없는 것으로 칩니다.
  개인 비상업용으로 쓰는 팬 도트입니다. GitHub Pages 는 공개되므로 권리자 요청이 오면 내려야 합니다.
- 저장은 기기 안(localStorage)에만 합니다. 브라우저 데이터를 지우면 키우던 디지몬도 사라집니다.
