# 스캔메이트

문서를 사진으로 찍으면 스캔한 것처럼 반듯하게 펴서 PDF 로 만들어 주는 웹앱입니다.
모든 처리는 기기 안에서 하고, 사진은 어디에도 올리지 않습니다. 오프라인에서도 동작합니다.

## 쓰는 법

1. **촬영** (또는 **앨범에서**) — 사진을 고르면 문서 테두리를 자동으로 찾습니다
2. **모서리 맞추기** — 동그라미(모서리)나 변 가운데 점을 끌어 맞춥니다. 끄는 동안 확대경이 뜹니다
3. **보정** — 선명하게(컬러) · 회색조 · 흑백 · 원본 중 고르고, 필요하면 회전합니다
4. **PDF 만들기** — A4 또는 사진 비율, 화질을 고르고 내려받거나 공유합니다

앨범에서 여러 장을 한 번에 고르면 자동으로 잘라 바로 넣습니다. 페이지를 누르면
다시 자르기·필터·순서 바꾸기·삭제를 할 수 있습니다.

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `js/scan.js` | 테두리 찾기, 원근 펴기, 스캔 필터 (외부 라이브러리 없음) |
| `js/pdf.js` | JPEG 페이지들로 PDF 쓰기 (JPEG 을 그대로 품는 DCTDecode) |
| `js/app.js` | 화면 흐름 |
| `sw.js` | 오프라인 캐시 |
| `tools/build-icons.py` | 아이콘 다시 만들기 (`python3 scanner/tools/build-icons.py`) |

### 처리 과정

- **테두리 찾기** — 사진을 360px 로 줄인 뒤 두 가지로 후보를 만듭니다.
  (1) 밝기 기준(Otsu)으로 밝은 종이 덩어리, (2) 윤곽선(Sobel)으로 둘러싸인 영역.
  가장 큰 덩어리의 볼록 껍질 안에서 가장 넓은 사각형을 찾고, 사각형에 얼마나 꽉
  차는지로 점수를 매깁니다. 못 찾으면 직접 맞추도록 기본 사각형을 줍니다.
- **펴기** — 네 모서리로 투영 변환을 구해 쌍선형 보간으로 펴냅니다. 가로:세로 비율은
  초점거리를 함께 추정하는 Zhang & He (2007) 방법으로 구해서, 비스듬히 찍어도 A4 는 A4 비율로 나옵니다.
- **스캔 필터** — 종이 바탕 밝기를 (줄이기 → 최댓값 필터로 글씨 지우기 → 흐림)으로
  추정한 뒤 나눠서 그림자·조명 얼룩을 없애고, 톤 곡선으로 바탕은 하얗게 글씨는 진하게 합니다.

## 알아 둘 점

- 페이지는 메모리에만 있습니다. 문서 사진은 개인정보일 때가 많아서 기기에 저장하지 않습니다.
  페이지가 있는 채로 창을 닫으려 하면 브라우저가 한 번 물어봅니다.
- 문서보다 어두운 바닥에 놓고 찍으면 테두리를 가장 잘 찾습니다. 흰 책상 위 흰 종이는 직접 맞춰야 할 수 있습니다.
